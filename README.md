# Combat Pokémon — TP fil rouge HTML / CSS / JS

TP pédagogique pour étudiants en Bac+2 / Bac+4 informatique : on construit pas à pas un
jeu de combat de Pokémon en HTML/CSS/JavaScript vanilla, en apprenant la manipulation du
DOM, les événements et les appels d'API (`fetch`), avec les données de l'API
[Tyradex](https://tyradex.app/docs) (gratuite, en français, sans clé).

## Contenu

- `tp/` — le sujet découpé en 8 étapes (fichiers AsciiDoc), avec pour chaque étape :
  objectifs pédagogiques, énoncé pas à pas, questions de compréhension, exercices bonus
  Bac+4. Voir `tp/README.adoc` pour le parcours et le découpage en séances.
- `tp/ressources/reference-api-tyradex.adoc` — fiche ressource sur l'API (endpoints, champs,
  exemples de JSON, règles d'utilisation).
- `solutions/etape-01/` … `solutions/etape-07/` — le code complet et cumulé de chaque
  étape (correction), prêt à ouvrir avec Live Server.

## Lancer le jeu

Ouvrir `solutions/etape-07/index.html` avec un serveur local (extension Live Server de
VS Code, ou `npx serve`), puis cliquer sur « Go Live ».

## Crédit

Données fournies par l'API [Tyradex](https://tyradex.app) — merci de créditer la source
en cas d'usage public, et de mettre les données en cache (voir étape 7).
