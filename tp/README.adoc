= TP fil rouge « Combat Pokémon » — Parcours pédagogique
:toc: left

== Principe

Un projet unique, construit **étape par étape**, qui accompagne un cours de
JavaScript autour de trois piliers : la **manipulation du DOM**, les
**événements** et les **appels d'API** (`fetch`). Les données proviennent de
l'API gratuite et française https://tyradex.app/docs[Tyradex].

Public : étudiants en Bac+2 et Bac+4 informatique. Chaque étape contient des
objectifs, un énoncé pas à pas, des questions de compréhension et des exercices
« Pour aller plus loin » (niveau Bac+4).

== Déroulé conseillé avec un cours

1. **Cours** : rappels JS (tableaux, objets, fonctions) puis présentation de `fetch` et des Promise.
2. **TP étapes 1–2** : les élèves codent en parallèle du cours, avec la solution en filet de sécurité.
3. **Cours** : le DOM (sélecteurs, création d'éléments) puis les événements (modèle de propagation, délégation).
4. **TP étapes 3–4** : recherche/filtres/fiche, puis sélection des combattants.
5. **TP étapes 5–6** : le combat, laissé plus en autonomie (c'est le moment « s'amuser »).
6. **TP étape 7** : pour les Bac+4, en autonomie guidée.
